## 2. 必须闭合的四项（验收对照）

### R2-1 · 左侧氛围插画（必须）
- **差距**：真源对局左栏有扁舟 / 棋篓类水墨插画；现站缺。
- **做法**：在对局/练习页左侧氛围区（玩家卡下方或侧栏背景层）补 **SVG/CSS 水墨插画**（扁舟 + 可选棋篓），低对比、不挡昵称/时钟/操作。
- **验收**：象棋与五子棋对局壳都能看到；不引入会员/付费暗示。

### R2-2 · 侧栏皮肤宣纸化（必须）
- **差距**：侧栏偏白卡+现代阴影，弱粉条仍偏 Web 工具感。
- **做法**：对局左右侧栏改为 **宣纸卡**（暖米底 `#F5F0E6` / `--bg-paper` 系、细线 `--line`、阴影更漫更淡）；去掉/弱化粉条、糖果色信息条；段位/状态 Tag 用朱砂浅底或炭灰，勿粉。
- **验收**：侧栏与中栏棋盘同属一套纸感，不再「白卡片贴在宣纸上」。

### R2-3 · 认输彻底降权（必须）
- **差距**：认输仍可能红描边/红字抢焦点。
- **做法**：认输改为 **ghost / 次级文字按钮**：无红实心、无粗红描边、无大红字；权重低于悔棋/求和主路径；危险性靠文案+确认框（已有国风 confirm）表达即可。
- **验收**：盲测一眼不会先看到认输；`actionBtn--resign` / `.ghost.danger` 在对局操作条上视觉弱于主操作。

### R2-4 · 象棋盘加深木纹（必须）
- **差距**：现盘偏浅偏纸，真源木质更深。
- **做法**：加深象棋盘木纹（多层渐变 + 细木纹噪点/SVG pattern），楚河汉界保留可读；勿做成塑料橙。
- **验收**：相对现站截图明显更「木」；五子棋可同步略加深浅木，但象棋优先。

### R2-5 · 可选：页缘山水/竹
- 对局页边缘淡山水/竹水印，opacity 低，**绝不挡棋盘点击与底部操作条**。
- 不做则在 RESULT 标明「可选未做」。
