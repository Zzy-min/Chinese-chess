## 2. 信息架构 vs 皮肤（必须分清）

### 2.1 皮肤（本轮主责，必须做）
- 色板、字体、圆角、阴影、描边、按钮主次、卡片层级  
- 水墨/竹/印鉴装饰的**边界与透明度**  
- 顶栏、侧栏、空态、列表行、Tag/徽章样式  
- 象棋盘木质感、五子棋浅木纹盘、棋子造型气质  

### 2.2 信息架构（不擅自扩 scope）
- **保留**现有路由与已上线能力（首页、对局/大厅、象棋对局、五子棋对局、棋谱、排行、观战、个人中心、房间创建/加入、AI 等——以仓库实际路由为准）。  
- 真源图中的「好友中心聊天气泡墙 / 赛事卡片流 / 棋谱库分类栅格 / 成就徽章墙」：  
  - **若路由已存在** → 只做视觉对齐；  
  - **若不存在** → **禁止**为对齐而新造整页业务；可在 brief 备注「缺页，仅设计对照」，或做与现入口等价的皮肤，不虚构数据。  
- **禁止**借视觉对齐塞入会员、商城、充值、 inductive 付费。

## 3. 全局设计系统（Token，执行时落到 CSS 变量）

### 3.1 色板（从真源取样，允许 ±2% 明度微调，禁止换色相）

| Token | 用途 | 建议值 |
|-------|------|--------|
| `--bg-paper` | 页面底 | `#F5F0E6` |
| `--bg-card` | 卡片 | `#FFFFFF` |
| `--ink` | 主文字 | `#2C2A26` |
| `--ink-muted` | 次文字 | `#7A746A` |
| `--line` | 细分割线 | `#E6DFD2` |
| `--cinnabar` | 主 CTA / 激活 / 象棋强调 | `#8B2E2E` |
| `--cinnabar-soft` | Tag 底、浅强调 | `#F3E4E0` |
| `--charcoal` | 次按钮、五子棋/中性强调 | `#333333` |
| `--bamboo` | 仅棋种点缀（五子棋卡、竹饰） | `#4D6756` |
| `--gold-coin` | 任务/积分小图标 | `#C6A35A`（克制使用） |
| `--shadow` | 卡片阴影 | `0 8px 24px rgba(44,42,38,.06)` |

**禁止**：霓虹、纯黑大底、高饱和蓝紫主色、厚重渐变玻璃拟态、iOS 设置灰列表感。

### 3.2 字体
- **标题 / 品牌 / 首页大句**：宋体/思源宋族（`Noto Serif SC` 或等价），字重中高，略增字距。  
- **导航 / 正文 / 数据**：系统无衬线（`PingFang SC` / `Noto Sans SC`）。  
- 首页主标示例气质：「落子之间，自有风雅」——必须是**衬线大标题**，禁止用默认无衬线冒充。

### 3.3 圆角 / 间距 / 阴影
- 大卡片：`16–20px`  
- 按钮 / 输入 / Tag：`8–12px`  
- 圆形快捷入口：正圆  
- 阴影：轻、漫、暖；**禁止**大投影黑边  
- 模块间距：宁疏勿挤；首页 Hero 与下方卡片区要有明确呼吸感  

### 3.4 按钮主次
1. **主按钮**：实心朱砂底 + 白字（象棋对局、快速匹配、签到主 CTA、关键确认）  
2. **次按钮**：炭灰实心或白底+细线（五子棋对局、取消、次要进入）  
3. **幽灵/文字按钮**：无底或极浅底（全部、查看、离开）  
4. **危险但降权**：认输 = 次级描边或中性实心，**不要**比「求和/悔棋」更抢眼到像唯一主按钮（可用朱砂但缩小或描边）  

### 3.5 水墨装饰边界（非常重要）
- **必须有**：首页 Hero 淡山水；模式卡内圆形/矩形水墨插画；赛事卡可有淡底图；角落竹叶/远山**低对比水印**。  
- **透明度**：装饰不得压过文字；正文对比度达标（深墨字在宣纸/白卡上）。  
- **禁止**：全屏实景照片抢戏、贴纸式 emoji 堆、高饱和插画、动态粒子特效默认开。  
- **印鉴**：可用小方朱印作风味点（签到等），尺寸小、不挡点击。

## 4. 分屏对齐规格（模块级）

以下每一屏写清：**布局骨架 / 必须有 / 禁止有 / 对齐验收点**。

### 4.1 首页 `#/home`（或等价）

**布局骨架（自上而下）**
1. 顶栏：左 Logo「棋」圆标+「轻棋局」+短副标；中导航；右音效/用户/退出  
2. Hero：居中大标题 + 副文案 + **双主 CTA**（象棋朱砂 | 五子棋炭灰或竹青）  
3. 两侧或侧旁：水墨圆形/扇面装饰（棋盘入画），不挡 CTA  
4. 四快捷：快速匹配 / 好友约战 / 赛事或人机 / 棋谱或个人——圆标或圆角小卡，图标线面简洁  
5. 底区三卡：每日签到 | 每日任务 | 双排行（象棋榜+五子棋榜）或「快捷入口+双榜」——以真源层次为准，白卡轻阴影  

**必须有**
- 衬线大标题气质句；双 CTA 并列且权重一眼可分  
- 宣纸底 + 淡水墨；导航当前项朱砂下划线  
- 排行榜行：名次圆标 + 昵称 + 分数；「全部」次按钮  

**禁止有**
- Hero 用厚重 Banner 广告图；三列以上主 CTA 并列  
- 会员角标、开局前付费墙  
- 快捷区图标五颜六色无体系  

**验收**
- [ ] 5 秒内看出「这是国风棋站首页」且主路径是象棋/五子棋  
- [ ] 截图叠真源：色温、圆角、卡片阴影同级，不串成蓝白后台风  

---

### 4.2 对局大厅 `#/play`（或等价）

**布局骨架**
- **左**：用户小结 + 竖向模式导航（首页/快速匹配/人机/好友/房间/观战…）；当前项朱砂实心  
- **中**：搜索大厅 + 筛选项（全部/象棋/五子棋/人机/观战）+ 双模式大卡（水墨插画+人数/进入）+ 最近对局列表  
- **右**：创建房间（主） / 加入房间（房号输入） / 推荐高手或榜摘要  

**必须有**
- 三栏桌面工作台；搜索+胶囊筛选  
- 模式卡图文并茂，主按钮清晰  
- 最近对局行：棋种标、结果、对手、时间/状态 Tag  

**禁止有**
- 只有文字列表无模式视觉卡  
- 左导航做成 Bootstrap 默认蓝 active  

**验收**
- [ ] 建房/加入/匹配三级动作不互相抢主色  
- [ ] 与真源同构：左导航-中内容-右操作  

---

### 4.3 象棋对局页

**布局骨架**
- **左**：对手卡（上）/ 我方卡（下）：头像、昵称、段位、大号时钟、行棋状态 Tag  
- **中**：木纹象棋盘 + 楚河汉界；顶条棋种/执子/回合 Tag；底条操作：悔棋、求和、认输、设置/离开  
- **右**：Tab「棋谱 | 分析 | 设置」；棋谱为步列表卡片  

**必须有**
- 木质纹理棋盘；红黑圆形棋子、楷/隶感文字  
- 时钟可读、当前回合 Tag 明确  
- 操作区不遮盘；认输不压过其它操作的视觉暴政  

**禁止有**
- 粉底大横幅挡盘；纯 CSS 假木（脏平涂）或塑料棋子  
- 三栏信息重复堆砌导致盘面缩小到难下  

**验收**
- [ ] 盘面仍是视觉中心；左右栏对齐真源「球员卡 + 谱」结构  
- [ ] 无糖果色状态条  

---

### 4.4 五子棋对局页

**同构**于象棋三栏；差异仅：
- 浅木纹/玉脂感十五路盘；黑白石子  
- 棋种色可用竹青点缀 Tag，**主 CTA 体系仍服从全局朱砂/炭灰**  
- 装饰可用竹石水墨，忌二次元贴纸  

**验收**
- [ ] 与象棋页同一壳；用户不会觉得「换了一个产品」  

---

### 4.5 好友中心（若已有路由）

**真源骨架**：左图标轨（好友/会话/申请）+ 中好友列表（在线点）+ 右聊天区（气泡：对方浅米、己方白/浅卡）+ 底输入  

**必须有**：搜索好友、在线状态、清晰会话气泡层级  
**禁止有**：把聊天做成 Discord 暗色风；花哨渐变气泡  

**若无路由**：本轮跳过实作，仅保留本节作对照，不造假页。  

---

### 4.6 赛事（若已有）

**真源骨架**：竖向赛事卡列表；卡上淡水墨底图、标题、日期、人数、状态 Tag、右侧「查看/报名」  

**必须有**：状态 Tag（进行中/报名中/已结束）视觉可分  
**禁止有**：电商大促红包风；假报名按钮无后端  

---

### 4.7 棋谱库（若已有）

**真源骨架**：分类列表/栅格；左小局面缩略 + 标题 + 简介 + 数量  

**必须有**：缩略棋形可读；分类名清晰  
**禁止有**：用随机风景图冒充棋谱封面  

---

### 4.8 个人中心

**真源骨架**：头像+昵称+ID+徽章；三统计（对局数/胜率/积分）；侧栏（资料/战绩/收藏/成就…）；主区成就/徽章栅格或战绩列表  

**必须有**：白卡统计；侧栏当前项可辨  
**禁止有**：会员开通大横幅；空白成就墙堆假数据忽悠验收
