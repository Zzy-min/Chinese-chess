# 早期影响研究方案

## 研究目标

验证无障碍象棋教练是否能帮助缺少教练资源的学生更准确地识别基础战术，并降低完成学习任务的交互障碍。该研究属于小样本可用性和早期影响验证，不用于推断普遍教育效果。

## 参与者

- 目标 5–10 人，优先招募缺少固定象棋教练或付费课程资源的学生。
- 只记录随机参与者编号，不记录姓名、学校、精确位置或联系方式。
- 未成年人必须由监护人或学校组织者明确同意；无法取得同意时只招募 18 岁以上学生。
- 是否使用辅助技术作为可选分组信息，仅记录“是/否/不愿回答”。

## 10–15 分钟流程

1. 简短说明、同意与基础经验自评，1–2 分钟。
2. 前测：3 道基础残局，无教学反馈，3 分钟。
3. 干预：键盘教程和 3 道自适应练习，5 分钟。
4. 后测：相同能力维度、不同局面的 3 道题，3 分钟。
5. 四个固定访谈问题，2 分钟。

固定访谈问题：

1. 哪条反馈最帮助你理解局面？
2. 哪一步最难操作或最难理解？
3. 如果没有真人教练，你是否愿意继续使用？为什么？
4. 有什么内容让你觉得系统说得不确定或不可信？

## 指标口径

- 正确率：在题目允许步数内完成的题数 / 总题数。
- 完成时间：从题目可操作到成功或主动结束的秒数。
- 提示依赖：主动展开建议或请求提示的次数。
- 重复错误率：同一错误类别在后测再次出现的人数 / 前测出现该类别的人数。
- 任务完成率：无需研究人员代操作即可走完整流程的参与者比例。
- 仅报告中位数、范围、人数和匿名引语；样本不足时不报告百分比改善结论。

## 数据表字段

`participant_id, adult_consent, assistive_tech, prior_level, pre_correct, pre_seconds, intervention_hints, post_correct, post_seconds, repeated_error_count, completed_without_help, quote_code`

禁止加入姓名、邮箱、电话、学校、精确地址、IP、设备指纹或自由文本身份信息。

## 停止规则

- 参与者可随时退出；退出数据默认删除。
- 出现隐私误采集、身份暴露或无法取得有效同意时立即停止该次测试。
- 教学反馈出现明确错误时记录题目和局面，停止使用该题，修复后重新验证。
