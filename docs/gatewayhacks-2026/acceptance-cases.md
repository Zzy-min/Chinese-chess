# 比赛版验收用例

## A. 游客核心路径

1. 清除站点 Cookie 与本地存储，打开学习页。
2. 不注册，选择一道人机象棋残局并启动教学模式。
3. 仅使用 Tab、方向键、Enter/空格和 Escape 完成一次走棋。
4. 收到“结论—原因—建议”反馈；反馈只引用可验证的将军、吃子、失子或引擎推荐信号。
5. 完成题目后得到不重复当前题的下一题推荐。
6. 刷新页面，浏览器存储可用时恢复学习统计；存储不可用时显示“本次进度不会保留”且练习仍可继续。

## B. 无障碍

- 棋盘只有当前活动格进入 Tab 顺序；方向键移动后焦点不丢失。
- 每个交叉点读出阵营、棋子、坐标、是否可走及选择状态。
- AI 落子、非法操作、将军、反馈和完成状态通过受控的 `aria-live` 区域各播报一次。
- 200% 缩放和 390px 宽度下，无关键按钮、反馈文本或棋盘操作被裁切。
- 高对比度下选择、可走与警告不只依赖颜色；所有核心控件有可见焦点。
- 开启系统减少动画后，无非必要移动或闪烁动画。
- 核心点击目标至少 44×44 CSS 像素。

## C. 教学可信度

- 非法走棋返回 `illegal_move`，不改变棋盘和统计完成状态。
- 解除将军、形成将军、明确吃子和立即高价值失子能被稳定分类。
- 信号冲突、引擎失败或无法可靠分类时返回 `neutral`，不猜测战略意图。
- `suggestedMove` 必须是当前局面的合法走法；无法证明时省略。
- 普通练习未启用 `coachMode` 时不返回教学判断，也不改变既有响应语义。

## D. 游客隔离与安全

- 游客 Cookie 为随机标识，不包含用户名、邮箱或设备信息，并设置 HttpOnly 与 SameSite=Lax。
- 游客不能读取其他游客或账号用户的进度、棋局和反馈。
- 游客练习不计入正式战绩、排行榜、成就或社区活动。
- 无效题目 ID、超长完成列表、负数/超范围错误计数返回 400，不触发任意资源读取。
- 过期或重启后丢失的游客棋局返回明确可恢复错误，引导重新开始。

## E. 回归与交付门禁

- `mvn test` 和 `mvn package` 通过。
- 资源契约测试覆盖新路由、语义属性和教学界面文案。
- 普通 AI 练习、正式对局、复盘、学习目录、账号进度和排行榜通过定向回归。
- 本地真实服务完成游客路径；Chrome + NVDA 完成人工路径。
- 桌面、390px 移动端、200% 缩放和高对比度截图完成视觉检查。
- 提交、推送、部署或 Devpost 更新前单独展示最终变更和材料并取得确认。
