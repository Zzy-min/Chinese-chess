# GatewayHacks 2026：无障碍象棋教练

## 项目边界

- 主赛道：Equity in Education。
- 目标用户：缺少专业教练资源的学生。
- 核心价值：游客无需注册，即可通过键盘和屏幕阅读器完成象棋残局学习，并获得基于棋规与引擎事实的确定性反馈。
- 比赛版只扩展象棋学习，不扩展五子棋或围棋，不使用外部大模型，不作医疗或治疗效果声明。

## 时间门禁

GatewayHacks 2026 的公开构建期为 2026-09-01 至 2026-10-02。2026-09-01 前只允许完成需求、研究设计、题库标签、线框和验收用例；参赛功能代码从构建期开始后实施。若主办方另行书面确认可提前开发，再更新此门禁。

## 既有能力基线

以下能力在比赛前已经存在，提交材料必须明确披露，不能计作本次新增成果：

- Java/Undertow 在线站点和账号系统；
- 象棋在线对局、AI 练习、复盘和残局初始 FEN；
- 学习目录、教程/残局完成记录和学习进度；
- 棋局分析、个人面板、排行榜和公网部署路径。

比赛期计划新增：

- 游客教学练习与隔离的短期会话；
- `coachMode`、确定性 `coachFeedback` 和自适应推荐；
- 等价语义棋盘、全键盘状态机与屏幕阅读器播报；
- 高对比度、放大字号、减少动画和本地游客进度；
- 前后测结果面板和匿名影响证据。

## 成功指标

- 游客能够在不注册、不配置 API Key 的情况下完成选题、走棋、反馈和下一题推荐。
- 核心学习路径可仅使用键盘完成，并通过 Windows Chrome + NVDA 人工验收。
- 断开外部模型服务后仍可完整演示。
- 5–10 名符合目标特征的参与者完成前后测；公开材料只使用汇总指标和匿名引语。
- 普通 AI 练习、正式对局、复盘、账号进度和排行榜无行为回归。
