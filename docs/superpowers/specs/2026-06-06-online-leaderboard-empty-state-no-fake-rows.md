# 在线前端榜单空态真实化设计

## 背景

首页与大厅页已经接入 `GET /online/api/community/leaderboard`，但当前前端在后端榜单为空时仍回退展示硬编码玩家和分数，例如“棋逢对手 2738”“棋圣无名 2738”。

这会让浏览器页面呈现出并不存在的榜单数据，违背“现有前端呈现功能必须有真实后端能力支撑”的目标。

## 目标

- 首页榜单和大厅榜单只展示后端返回的真实榜单数据。
- 当后端榜单为空时，展示明确空态，不展示伪造玩家、伪造排名或伪造分数。
- 保持榜单的象棋/五子棋切换、社区页跳转和后端接口不变。

## 非目标

- 不改排行榜计算规则。
- 不新增会员、等级或积分体系。
- 不改社区榜单接口响应结构。

## 验收标准

1. `src/main/resources/online/app.js` 不再包含硬编码假榜单用户名和固定假分数。
2. 首页与大厅榜单在无数据时显示真实空态文案。
3. 有后端榜单数据时仍正常显示用户、排名和分数。
4. 浏览器验收覆盖无假榜单文字泄漏。
