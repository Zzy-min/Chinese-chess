# Online 象棋棋子视觉恢复设计

## 背景

当前 Online 象棋棋盘已切换为线稿风格，但棋子仅显示文字，缺少圆形棋子承载，用户反馈“棋子呢？”。

## 目标

1. 在保留第 3 张参考图线稿棋盘的前提下，恢复“圆形棋子”视觉承载。
2. 红黑双方棋子颜色清晰可辨，选中态有明确高亮。
3. 不改棋盘映射逻辑、不改后端数据结构。

## 方案

仅修改 `online/app.css`：

1. `.xiangqiCell .piece` 改为圆形棋子容器（木色渐变 + 边框 + 阴影）。
2. `.xiangqiCell.is-black .piece` 保持黑字；红方保留红字。
3. `.xiangqiCell.is-selected .piece` 改为外圈高亮，不破坏棋子底色。

## 验证

1. `mvn -q test` 通过。
2. 本地截图确认象棋分析页棋子为圆形实体，不再是裸字。
3. 公网资源版本与 CSS 标记更新生效。
