# Online Guofeng Web Redesign Without Membership

## Summary
用户要求将 `src/main/resources/online/` 下的网页端整体改成参考图所示的国风水墨桌面站点，同时保持现有功能不变或增强，并明确不要“会员”功能。

## Scope
- 首页 `#/home`
- 对局大厅 `#/play`
- 棋种入口 `#/play/xiangqi`、`#/play/gomoku`
- 对局页 `#/game/*`、练习页 `#/practice/*`、分析页 `#/analysis/*`
- 顶部导航与辅助入口

## Non-Goals
- 不新增会员/付费体系
- 不修改后端接口协议
- 不改变房间、练习、分析的核心业务语义

## Frontend Brief

### Task
- 对象：在线站点桌面 Web 界面
- 范围：视觉系统、首页、大厅、棋盘页、导航与帮助入口

### Goal
- 用参考图的宣纸、水墨、木纹棋盘视觉重构在线站点
- 保持用户现有的创建房间、加入房间、AI 练习、观战、分析等能力

### Audience
- 想要在线对弈、练习与复盘的中文棋类用户
- 主要使用桌面端浏览器，移动端保留可用但不是本次主视觉目标

### Narrative
- 首页先讲“这是什么”与“两种主入口”
- 大厅页承担创建/加入/浏览房间与最近对局
- 棋盘页突出沉浸式对局桌，信息按“对手信息 - 棋盘 - 记录/分析”展开

### Visual Direction
- 品牌气质：国风、典雅、静谧、木质工艺感
- 视觉锚点：宣纸背景、水墨山峦、竹叶、木纹棋盘、朱砂/竹青双色按钮
- 配色：暖米白中性色 + 朱砂红主强调 + 竹青绿副强调
- 字体：楷体/宋体用于标题，现有中文无衬线用于正文

### Interaction
- 主 CTA：开始对局 / 创建房间 / 进入大厅
- 次级动作：加入房间、AI 练习、进入分析、观战、帮助
- 禁止会员入口；顶部不出现“会员”标签或相关文案

### Constraints
- 必须保留：现有 route、登录、房间、练习、分析、社区/排行榜、观战数据
- 明确避免：会员入口、付费暗示、移动端专属布局覆盖桌面主视觉
- 响应式要求：桌面优先，移动端不破版

## Design Decisions
1. 默认入口回到 `#/home`，`#/welcome` 不再作为空 hash 默认页。
2. 顶部导航改为：`首页 / 对局 / 练习 / 排行榜 / 社区 / 帮助`。
3. `#/play` 改为桌面工作台式大厅：
   - 左侧功能导航
   - 中部搜索、分类、棋种入口、最近对局
   - 右侧创建/加入房间与排行榜摘要
4. 棋盘页统一为三栏：
   - 左栏玩家/时钟/局面摘要
   - 中栏棋盘与主操作
   - 右栏记录/分析标签
5. 所有“会员”入口全部移除，不用占位词替代。
