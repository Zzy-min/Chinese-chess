# 规格说明：轻棋局个人主页（#/me）UI 重构与异常修复

## 1. 现状与问题定义

用户反馈在访问 `http://127.0.0.1:18388/online#/me` 时存在严重 UI 异常。经 Playwright 真实浏览器（Chromium 自动化截图与度量）诊断，查出以下关键异常根因：

### 1.1 桌面端主页结构坍塌（严重功能/视觉 Bug）
- **现象**：在 1440px 桌面端，个人信息卡片被挤压在左侧 250px 窄列内，头像严重变形缩扁成窄椭圆，用户名溢出；原本应在左侧的侧边栏菜单占据了整个右侧宽栏；下方的“最近对局”和“学习与成就”又折行挤压到左侧 250px 窄栏内，导致“最近对局”卡片被挤压至 20px 宽度，文字竖向拆分单字断行（如“还\n没\n有\n对\n局\n记\n录”）。
- **根因**：`app.js` 的 `renderProfile()` 函数在 overview 路由下强行返回了三子节点结构 `<div class="profilePage profilePage--m9">`（包含 `.profileMain--top`、`.profileSidebar`、`.profileMain--bottom`）。而在 `app.css` 中 `.profilePage` 声明为两列网格（`grid-template-columns: 250px minmax(0, 1fr)`），未对桌面端的 `--m9` 进行任何网格区域适配，导致三元素按网格顺序依次流转填充，造成灾难性排版错乱。

### 1.2 头像与文本弹性挤压（移动与桌面兼有）
- **现象**：`.profileUserRow .avatar` 在空间受限时被 flex 压缩变形；320px/375px 下长用户名、签名与“编辑资料”按钮空间冲突，导致换行突兀；印章文字未对齐。
- **根因**：缺少 `flex-shrink: 0`、`aspect-ratio: 1/1` 及 `min-width` / `min-height` 约束；缺少 `text-overflow: ellipsis` 截断保护。

### 1.3 移动端 320px 小屏下导航菜单文字折行破碎
- **现象**：移动端双列九宫格样式的 7 个功能卡片中，副标题（如“管理个人资料”、“系统消息与活动”）在 320px 宽度下被挤成 3 行，卡片高低不平、极度拥挤。
- **根因**：按钮内部 padding 与图标占据过大空间，未设置 `white-space: nowrap` 与 `text-overflow: ellipsis`。

### 1.4 未登录游客态（Guest State）体验简陋冰冷
- **现象**：未登录用户直接访问 `#/me` 时，弹出的登录弹窗背后是一个巨大粗糙的灰色占位块（`<section class="placeholder"><h2>个人</h2><p>登录后可查看战绩...</p></section>`），既无登录/注册行动引导，又无轻棋局水墨雅致氛围。
- **根因**：未实现游客态专属组件 `renderProfileGuest()`，仅调用通用冷灰色 `renderPlaceholder`。

### 1.5 设置页面 Android 版本信息行样式丢失
- **现象**：`me/settings` 中的 `<button class="settingRow mobileVersionRow">` 渲染为系统默认原生丑陋按钮（灰色凹凸边框、居中灰字）。
- **根因**：`app.css` 中缺少 `.settingRow` 和 `button.settingRow` 样式规则。

### 1.6 移动端子页面层级混乱与返回链路缺陷
- **现象**：在手机端进入 `#/me/records` 或 `#/me/settings` 等子路由时，顶部依然重复堆叠全部 7 个功能入口卡片，把真实内容推到首屏之外；同时顶部返回按钮直接跳回 `#/home`，违背“子页面返回父级个人中心”直觉。

## 2. 重构与设计目标

1. **统一水墨国风审美规范**：
   - 宣纸暖白底色（`#FAF7F0` / `#FCFAF7`）、朱砂红强调色（`#9D3023` / `#8C2E21`）、松烟墨色文字（`#2C2825`）、古韵竹木边线（`rgba(220, 205, 185, 0.6)`）。
   - 印章质感头像（圆形朱红渐变、古印字样“棋”/首字、微浮雕内阴影）。

2. **桌面端（>= 769px）规范化双栏对齐**：
   - 宽度收敛居中：`max-width: 1200px; margin: 0 auto;`。
   - 左侧（260px）：固定功能导航栏 `profileSidebar`，清晰分组（“我的棋局”、“成长印记”、“弈事服务”），选中态朱砂红底。
   - 右侧（1fr）：根据当前 tab 渲染对应内容：
     - **概览态（Overview）**：个人名片卡（头像不畸变、对局/胜率/负局/成就四维战绩） + 概览双列（左列：最近对局记录；右列：研习与成长进度卡片）。
     - **子页面（Records / Study / Achievements / Inbox / Settings / Help）**：内容占据全宽右栏，统一内边距与宣纸卡片质感。

3. **移动端（<= 768px）自适应与弹性流**：
   - **概览页**：
     - 顶部：紧凑精致的印章名片卡（头像保证 56~64px 坚决不椭圆变形，用户名单行超出省略，右侧优雅轻量编辑按钮）。
     - 中部：双列金石印风功能菜单卡片，文字超出省略，320px 下自适应紧凑字距与间距，保障完全对齐。
     - 底部：最近对局与学习成长卡片，流畅纵向流。
   - **子页面**：
     - 移动端进入子页面时，顶部返回按钮准确指向 `#/me`。
     - 隐藏冗余的 7 宫格大卡片，代之以轻盈的水墨滚动胶囊导航（Pill Tabs），既能随时在各 Tab 间快速横滑切换，又把页面焦点完全留给子页面主要内容。

4. **游客态（Guest State）雅致待客页**：
   - 替换粗糙的冷灰 `placeholder` 为雅致水墨“客卿待客”卡片：
     - 水墨徽章：“客”字朱红印章。
     - 标题：“轻弈知己 · 登堂入室”。
     - 文案：“登录轻棋局账号，云端同步棋力段位、归档名局棋谱、挑战每日残局与解锁勋章”。
     - 主行动 CTA：“立即登录”与“注册新棋友”，以及“以客卿身份先去下棋”。
     - 四大专属功能预览卡片（对弈留痕、云端推演、段位进阶、残局秘籍），引导转化。

5. **偏好设置与子功能完善**：
   - `.settingRow` 全面统一美化：水墨质感圆角卡片、行高与对齐统一。
   - Android 版本信息按钮融入水墨卡片体系，点击反馈明确。
   - 学习档案（Study）与消息中心（Inbox）采用两列/流式自适应卡片，告别空缺列不对齐。

## 3. 验收标准

1. **自动化诊断零报错**：
   - 运行 Playwright 诊断，桌面端、平板端、手机端（375px 和 320px）全端无水平溢出（`hasHorizontalOverflow === false`）。
   - 路由切换无 JavaScript 控制台错误。
2. **多视口视觉完全正常**：
   - 桌面端（1440px）：居中舒适双栏布局，左侧 260px 侧边栏，右侧主内容区，无挤压单字折行。
   - 平板端（768px）：自适应流式排版，无遮挡无重叠。
   - 手机端（375px / 320px）：头像正圆不压扁，菜单文字优雅单行截断，无任何元素溢出或按钮错位。
3. **单元与集成测试全绿**：
   - `mvn test` 全部通过。
