# 本地工作树全量提交并部署设计

日期：2026-05-03

## 背景
当前 `D:\claude项目\XiangqiGame` 分支 `feat/vps-compose-caddy-deploy` 存在大量未提交本地改动（代码、资源、测试、文档与工具脚本）。  
用户要求先从本地仓库核对改动，再“全部提交并部署”。

## 目标
1. 将本地工作树改动完整提交为单次可追溯变更。  
2. 避免直接部署落后分支导致线上回退，最终上线目标分支仍为 `main`。  
3. 部署后验证公网站点与核心接口可用。

## 非目标
1. 不裁剪本地改动范围（按用户要求全量提交）。  
2. 不重写远端历史（不 force push）。

## 策略
1. 在本地 `feat/vps-compose-caddy-deploy` 提交所有变更。  
2. 将该提交并入最新 `origin/main` 后推送 `main`。  
3. 使用部署脚本部署 `main` 并执行本地/公网验收。

## 验收标准
1. 本地工作树改动全部进入 git 提交。  
2. `origin/main` 包含该提交内容。  
3. 部署日志显示 `Deploy completed.`，并且公网页面/接口返回正常。
