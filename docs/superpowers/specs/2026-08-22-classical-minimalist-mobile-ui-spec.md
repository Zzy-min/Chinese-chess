# 移动端古典简约与高效率设计规范 (Classical Minimalist & High-Efficiency Spec)

## 1. 核心设计理念与愿景

### 1.1 核心诉求
- **古典简约 (Classical Elegance & Minimalism)**：摆脱现代 SaaS 卡片墙与大块臃肿的圆角堆叠，汲取中国传统文人雅趣、宋明极简线装书卷与木版金石印章的美学精髓，运用纯净宣纸底色、宋体/楷体标题、细腻水墨墨线分割和朱砂印章点缀。
- **效率至上 (High Efficiency & Density)**：移动端视口寸土寸金，拒绝过大的留白浪费。首屏即见核心对战与关键信息，减少垂直无谓翻页，采用高信息密度的行式列表（List Rows）、两列矩阵（2-Column Grids）与紧凑工具条（Action Ribbons）。
- **去卡片化 (De-cardification)**：严禁使用层层嵌套、超大内边距的大卡片堆叠；改用古典墨线分割（Ink Dividers）、双列键值排布（Classical Key-Value Rows）和紧凑印章标识（Seal Badges）。

## 2. 色彩与字体体系 (Classical Palette & Typography)

### 2.1 雅致国风色盘
| 语义 | 颜色变量 | 色值 | 用途说明 |
| :--- | :--- | :--- | :--- |
| **宣纸底** | `--cl-paper` | `#fcfaf6` | 全局背景，温润质感，柔和不刺眼 |
| **素绢白** | `--cl-surface` | `#ffffff` | 内容区块与操作行背景 |
| **深纸色** | `--cl-paper-deep` | `#f4efe6` | 边框衬底、子选项卡与辅助底色 |
| **焦墨色** | `--cl-ink` | `#221e19` | 主标题、核心文字与重要数据 |
| **淡墨色** | `--cl-muted` | `#6b6357` | 辅助说明、副标题、时间戳与标签 |
| **朱砂红** | `--cl-cinnabar` | `#9c2f22` | 主 CTA、胜局标识、红方印章、高光选定 |
| **松烟青** | `--cl-green` | `#2f5f4a` | 绿方印章、辅助标签、和平/挑战入口 |
| **泥金光** | `--cl-gold` | `#b97c38` | 榜首金章、破局星级、荣誉边饰 |
| **墨线色** | `--cl-border` | `rgba(60, 48, 36, 0.12)` | 极细分割线与边框 |

### 2.2 字体排印规范
- **标题**：`font-family: "Songti SC", "Source Han Serif SC", "STSong", "KaiTi", serif;`，字重 700，字间距 `0.04em`。
- **正文与操作**：系统标准无衬线字体，字重 500/600，行高 1.4。
- **数字与时钟**：`font-variant-numeric: tabular-nums;`，确保对齐与清晰度。

## 3. 各功能页面设计规范

### 3.1 首页 (`#/home`)
1. **古典顶栏**：
   - 左侧：朱砂红方印 `【棋】` + “轻棋局”，极简优雅。
   - 右侧：圆形客/友头像徽章，点击直达个人中心。
2. **高效率对局直达条 (Quick Match Ribbon)**：
   - 告别笨重大 Hero 区域，紧凑横幅展示当前棋种（象棋/五子棋）与 5 分钟快棋。
   - 包含一键“立即匹配”主按钮与棋种切换微调。
3. **四格古典模式入口 (Compact Mode Matrix)**：
   - 4 格等宽紧凑按钮（真人对战、AI 磨砺、好友约战、残局闯关），带有宋体字与小巧印章。
4. **最近对局与未完进度 (Recent & Resume)**：
   - 续弈快捷条（若有未完局）以醒目墨线显示。
   - 最近 3 场对局使用紧凑行排布（胜/负/和印章小标、对阵双方、步数与时间），单行高度 44px，点击直达复盘。

### 3.2 对局大厅 (`#/play`)
1. **顶栏**：返回键、标题“寻弈大厅”、刷新按钮。
2. **快捷入口行**：
   - 5分钟快棋匹配、人机练习、创建房间一键操作。
   - 6 位房间码输入框与加入按钮紧凑集成在单行内。
3. **公开房间列表**：
   - 紧凑行式列表：房主昵称、房间号、棋种小印（象/五）、局时与状态，右侧直接提供“挑战/加入”按钮。

### 3.3 棋盘与记录对弈桌面 (`#/game`, `#/practice`, `#/analysis`)
1. **棋盘主视图**：
   - 顶部“棋盘 / 记录”分段切换器。
   - 双方对弈信息采用上下精简时钟条，棋盘居中最大化适配屏幕。
   - 底部 4 键紧凑操作栏（悔棋、求和、认输、翻转），高度 42px，触控灵敏。
2. **记录面板视图 (`记录` Tab)**：
   - 顶部均分 4 选项卡（局势、棋谱、分析、设置）。
   - 局势：紧凑双列键值对，清晰展示对局状态、总局时、剩余时间、双方选手。
   - 棋谱：双列步数网格，着法简练规范，支持独立触控滚动。
   - 分析与设置：极简提示条与开关按钮。

### 3.4 学习残局题库 (`#/learn`)
1. **水平分类筛选胶囊**：全部、残局挑战、基础教程、开局库。
2. **高密度题库列表**：
   - 紧凑行式卡片：残局标题、破局星级、完成状态印章（已破局/未解）、一键“挑战”按钮。
   - 展开教程：紧凑图文与关键着法列表。

### 3.5 观战、社区与个人中心 (`#/watch`, `#/community`, `#/me`)
1. **观战**：对局双方、手数与即时入座按钮行。
2. **排行榜**：金银铜古典名次标、昵称、胜局与积分紧凑表格。
3. **个人中心**：战绩数据 3 列横向统计条（总局数、胜率、积分），下方为偏好设置紧凑列表。

## 4. 验收与验证标准
1. 所有页面的核心 CTA 位于首屏可见区域，无需大幅翻滚。
2. 单个列表项高度控制在 44px - 56px 之间，避免单项占用超过 120px 高度。
3. 保证真实 Android 手机（1260x2800 及 360px+ 各类移动视口）响应式无水平溢出。
4. 全量自动化测试（`mvn test`）64/64 保持 100% 通过。
