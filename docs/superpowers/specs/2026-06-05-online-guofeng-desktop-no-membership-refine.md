# Design Spec: Online Guofeng Desktop Refinement Without Membership

## 1. Task
- 对象：`/online` 网页端桌面国风主界面
- 范围：`#/home`、`#/play`、`#/practice/*`、`#/game/*`、`#/analysis/*`、`#/learn`、`#/me`

## 2. Goal
- 让当前桌面网页更接近用户提供的国风四宫格参考图。
- 保留现有可用功能：在线对局、AI 练习、建房/入房、观战、排行榜、复盘、个人页、帮助。
- 移除会被理解为“会员功能”或“付费等级体系”的呈现，包括导航、徽章、假等级、VIP 字样。

## 3. Audience
- 主要受众：希望在网页上进行象棋与五子棋在线对局、练习和复盘的普通用户。
- 使用场景：桌面浏览器为主，强调首页导流、对局大厅转化和棋桌沉浸感。

## 4. Narrative
- 首页第一眼应理解：这是一个免费、国风、双棋种在线对弈平台。
- 页面叙事顺序：
  1. 品牌与主入口
  2. 双棋种模式选择
  3. 免费能力与常用入口
  4. 对局热度与排行榜
  5. 进入大厅或开始练习

## 5. Visual Direction
- 品牌气质：古雅、留白、克制、可用。
- 视觉锚点：宣纸底色、水墨山水、木纹棋桌、朱砂红与竹青绿双主色。
- 版式节奏：顶部横向导航，正文以大留白卡片与三栏/三段结构组织。
- 配色策略：米白中性底色 + 朱砂红/竹青绿强调，避免现代会员金光或 VIP 紫色体系。
- 字体策略：标题与重点数字使用楷体或宋楷感衬线，正文保持易读无衬线。

## 6. Membership Removal Rules
- 顶部导航不得出现“会员”字样。
- 任何用户信息区不得出现 `VIP`、`LV.x`、付费暗示、专属门槛描述。
- 棋桌、大厅、个人页中的身份标签改为免费且可解释的元信息，例如：
  - 棋种偏好
  - 当前状态
  - 最近活跃
  - 段位/战绩（若为真实通用能力，不做付费绑定）
- “俱乐部”若作为观战/社区壳入口存在，统一改回“社区”或“公开观战”这类免费能力表达。

## 7. Page Requirements

### 7.1 Topbar
- 导航结构统一为：`首页`、`对局`、`练习`、`排行榜`、`社区`、`帮助`
- 右上角保留：音效开关、个人入口、登录/注册或退出

### 7.2 Home
- 主 Hero 更贴近参考图的左右水墨插画 + 中部双主入口。
- 首页信息区不再放“每日签到”和“每日任务”作为主结构。
- 首页下半区调整为三组免费能力：
  - 快捷入口
  - 对局实况 / 最近对局
  - 排行榜

### 7.3 Play Lobby
- 左侧边栏改为免费能力导向：
  - 首页
  - 对弈大厅
  - 公开观战
  - 残局练习
  - 战绩总览
  - 排行榜
  - 设置 / 帮助
- 移除 `LV.6 棋圣`、`俱乐部`、签到卡片等会员感/运营感强的元素。
- 中部保留检索、分类胶囊、双棋种大卡片、最近对局。
- 右侧保留建房/入房与排行榜。

### 7.4 Practice/Game/Analysis
- 保持三栏棋桌结构与已有棋盘自适应逻辑。
- 左栏身份说明改为真实对局信息，不使用 `vipBadge` 语义承载会员感文案。
- 右栏 Tab 与底部操作不减功能，只做视觉精修与文案去会员化。

### 7.5 Learn
- 从“棋谱库”改回更贴近导航语义的“练习”页，但保留题库/教程/练习入口。
- 列表内容文案更偏公开学习资源，而非专属内容包。

### 7.6 Profile
- 保留个人数据、对局数、胜率、积分、收藏等通用能力。
- 移除硬编码 `ID: 10086 · 业余1级` 这类假身份展示，改为用户真实用户名 + 通用摘要。

## 8. Constraints
- 不改后端接口协议与棋局规则。
- 不移除已有真实能力。
- 新增表达优先复用现有数据；无真实数据时用中性占位，不制造会员体系暗示。
- 本次以桌面端为主，同时保证现有移动端路由不被破坏。

## 9. Verification
- 静态检查：`node --check src/main/resources/online/app.js`
- 构建检查：`mvn -q -DskipTests compile`
- 视觉验收：
  - `#/home`
  - `#/play`
  - `#/practice/*`
  - 宽屏至少一个桌面视口
- 成功标准：
  1. 页面结构更接近参考图。
  2. 不再出现会员、VIP、LV、俱乐部等会员感呈现。
  3. 现有对局、练习、入房、复盘入口仍可达。
