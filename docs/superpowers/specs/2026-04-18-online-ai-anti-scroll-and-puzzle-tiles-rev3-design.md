# Online AI 防滑动与题库三级方块平铺设计（Rev3）

## Summary

本轮聚焦两件事：

1. 仅 `#/practice/*`（AI 练习）彻底去除页面与棋盘区上下滑动，降低触摸误触，稳定选子与落子。
2. 学习题库三级主题改为小方块平铺，并将题目卡片收敛为核心信息展示。

## Design

### 1) 仅 AI 页锁滚动

- 在前端路由渲染层增加 `route-practice-locked` 页面类，仅用于 `practice` 路由。
- 布局约束：
  - 页面级容器固定到 `100vh`，关闭页面滚动；
  - 棋盘区 `overflow:hidden`；
  - 记录区保留内部滚动。
- 触控约束：
  - AI 页棋盘容器设置 `touch-action` 与 `overscroll-behavior`，避免拖动手势触发滚动抢占。

### 2) 三级主题方块平铺

- 题库三级主题从胶囊按钮改为固定尺寸小方块网格（`learnThemeTiles`）。
- 桌面：5 列单行；移动端：3 列自动换行形成 3+2。
- 标签文案收敛为短词：`全部 / 战术 / 杀法 / 局面 / 残局`。

### 3) 题目卡片收敛

- 题目列表默认仅显示：
  - 标题；
  - 核心元信息（棋种/难度/主题）；
  - 单行摘要（超出省略）；
  - 行动按钮（完成/按题开局）。
- 默认不渲染大段详情（局面说明/来源/提示/解法等），减少纵向占用。

## API / Compatibility

- 后端 HTTP API 与路由协议不变。
- `#/learn/puzzles/:theme` 深链接保持兼容。
