# Online 在线对局朝向 + 落子可见性 + 河界层级修复设计（Rev2）

## Summary

本轮在不改后端 API 的前提下，修复在线对局体验中的五个问题：

1. 落子提示不明显；
2. 楚河汉界语义和层级不物理；
3. 在线对局执棋信息不清楚；
4. 在线对局棋盘未按执棋方视角展示；
5. 落子操作存在明显卡顿感。

## Design

### 1) 在线对局视角映射（仅 `#/game/*`）

- 对局页按 `viewerSide` 应用前端视角映射：
  - 象棋：`viewerSide=BLACK` 时翻转为黑方在下；`RED` 保持红方在下。
  - 五子棋：`viewerSide=WHITE` 时翻转为白方在下；`BLACK` 保持黑方在下。
- 渲染与点击统一使用“显示坐标 -> 棋盘坐标”映射，避免视觉方向变化导致落子坐标错误。
- 练习页与分析页保持当前方向，不受此次映射影响。

### 2) 执棋信息明确化

- 在线对局状态区增加明确文案：
  - `你执 <side>`
  - `对手执 <side>`
  - `轮到你/对手（side）`
- 侧重“玩家身份 + 执棋方向 + 当前手”三件信息同时可见，消除分棋歧义。

### 3) 楚河汉界语义与层级修复

- 河界文案随视角切换：
  - 红在下：`楚河 汉界`
  - 黑在下：`汉界 楚河`
- 层级关系重排：
  - 河界文字在棋盘底纹之上；
  - 河界文字在棋子和棋子阴影之下；
  - 结果是棋子经过河道口时可自然遮住文字局部，不出现文字压在棋子上的异常。

### 4) 落子标记增强

- 用户与 AI 统一采用 `from/to` 双点标注结构。
- `to` 点增加短时脉冲动画，`from` 点采用高可见边框样式。
- 同结构不同颜色区分己方/对手，显著提高木纹背景下的可读性。

### 5) 在线对局交互卡顿治理

- 象棋选子/改选/取消选择不再整页重渲染，改为棋盘局部状态刷新。
- `sendMove` 过程减少重复渲染：提交阶段与完成阶段仅保留必要更新，移除冗余 finally 重绘。
- 保留 `moveInFlight + moveRequestToken` 并发保护，阻止旧响应覆盖新状态。
- 在线局收到 WS 增量时优先走局部区域刷新（棋盘/状态/记录），失败时回退全量 `render()`。

## API / Compatibility

- 后端 HTTP API：无新增、无破坏性变更。
- 前端路由：无新增；仅增强 `#/game/*` 页面内渲染和交互策略。
