# 轻棋局移动端 UI 界面全景优化设计规范 (Mobile UI Optimization Spec)

## 1. 概述与设计愿景

“轻棋局（XiangqiArena）”定位为兼具东方水墨雅致意境与现代移动端流畅体验的在线棋类对弈平台。
本次移动端 UI 界面全景优化旨在解决现有移动端在视觉层次、触控交互、棋盘适配、操作响应、国风美学统一性等方面的痛点，打造“沉浸对弈、指尖生风”的极致移动端棋类体验。

### 2.2 字体与版式 (Typography)
- **书法与大标题**：`"Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", "KaiTi", serif`
  - 增强水墨行书韵味，字间距微微加宽（`letter-spacing: 0.06em`）。
- **界面文本与数字**：`"PingFang SC", "Microsoft YaHei UI", -apple-system, sans-serif`
  - 倒计时时钟与比分使用 `font-variant-numeric: tabular-nums`，防止数字跳动。

### 2.3 触控尺寸与无障碍规范 (Touch Ergonomics)
- 所有可交互按钮、选项卡与入口的最小触控面积不低于 **44px × 44px**。
- 支持移动端 Safe-Area 适配（`env(safe-area-inset-top)` 与 `env(safe-area-inset-bottom)`）。
- 点击反馈：全站统一轻量触觉微动（`transform: scale(0.97)` + 柔和过渡 `cubic-bezier(0.2, 0.9, 0.3, 1)`）。

## 3. 核心页面优化设计

### 3.1 移动端首页 (Mobile Home)
1. **Header 品牌区**：
   - 朱砂红印章 Logo（“棋”）+ 品牌名“轻棋局” + 诗意副标“落子之间，自有风雅”。
   - 右上角个人印章头像（显示登录用户名首字或“客”字印章），点击直达个人中心。
2. **Hero 视觉主卡**：
   - 水墨太极/楚河汉界金线微光背景。
   - 醒目标语：“下一局，从这一手开始”。
   - 朱砂红全宽主 CTA 按钮“快速开始一局”，附带微光渐变，一键唤起开局面板。
3. **快捷模式金刚区 (Quick Mode Grid)**：
   - 4 格高频卡片：
     - ⚡ 真人对战（匹配在线棋友）
     - 🤖 人机练习（智能 AI 随开随战）
     - ⚔️ 好友约棋（创建/加入房间）
     - 🧩 残局闯关（每日残局破解）
4. **进行中/继续对局动态条 (Active / Continue Banner)**：
   - 若有未完对局或房间，展示呼吸光晕提示“继续对局”；若无则推荐“今日残局”。
5. **最近战绩速览 & 排行榜摘要**：
   - 战绩卡片展示棋种印章（象/五）、红黑胜负印章、对局时间与回放入口。
   - 榜首荣誉小卡，激励对弈。

### 3.2 快速开局弹层 (Quick Start Bottom Sheet)
- 底部上滑半模态弹窗，带防误触顶部指示条。
- 棋种双段切换器（中国象棋 / 五子棋）。
- 模式卡片：
  - ⚡ 快速匹配（5 分钟场 / 10 分钟场）
  - 🤖 人机对弈（简单 / 中等 / 困难 / 特级大师）
  - ⚔️ 好友对弈（创建私密房间并复制邀请码）

### 3.3 棋盘与对弈工作台 (Mobile Game Desk)
1. **上下对手布局 (Vertical Board Arena)**：
   - 上方：对手信息卡片（头像、昵称、Elo 积分、倒计时时钟、落子指示灯）。
   - 中间：动态自适应棋盘（居中、无水平溢出、高 DPI 纹理、木纹/纸质质感）。
   - 下方：己方信息卡片（头像、己方昵称、倒计时时钟、思考中徽章）。
2. **走子辅助与微动效**：
   - 选中棋子微浮起光晕；
   - 合法着法落点柔和金圈/绿点；
   - 上一步走子红绿轨迹光圈；
   - “将军！”/“绝杀！”水墨书法警示横幅浮现。
3. **移动端底部操作条 (Mobile Wood Actions Bar)**：
   - 4-5 键横向排布：悔棋 (Undo)、求和 (Draw)、认输 (Resign)、提示 (AI Hint)、翻转 (Flip)。
   - 认输/求和添加确认二次防误触交互。
4. **棋盘 / 棋谱 选项卡切换 (Board & Moves Tabs)**：
   - 棋盘与招法记录自由切换，清晰查看步数、红黑着法记谱（如“炮二平五 马8进7”）。

### 3.4 残局与学习中心 (Mobile Learn & Puzzles)
1. **子分类标签**：教程 (Tutorials)、残局闯关 (Endgame Puzzles)、定式练习 (Practice)。
2. **主题筛选胶囊**：全部、战术、杀法、残局 FEN、经典杀着。
3. **残局卡片美化**：
   - 难度星级展示（★☆☆ 至 ★★★）；
   - “已破”朱砂印章标记 / “未破”水墨空心印章；
   - 一键“开始挑战”或“查看解析”。

### 3.5 观战大厅与社区排行榜 (Mobile Watch & Community)
1. **观战卡片**：双方棋手名称、段位积分、当前回合步数、观战人数、一键进入。
2. **社区排行榜**：
   - 冠亚季军金/银/铜印章徽章与祥云装饰；
   - 胜率条、净胜场、段位展示。

### 3.6 结算弹窗 (Game End Modal)
- 水墨大印章印记：“红方胜出” / “黑方胜出” / “握手言和” / “绝杀”。
- 积分变动小标签（如 `+16分`）。
- 快捷操作按钮：“再来一局”（主按钮）、“复盘分析”（次按钮）、“返回大厅”。
