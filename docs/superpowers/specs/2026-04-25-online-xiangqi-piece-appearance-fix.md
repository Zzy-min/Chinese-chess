# Online 象棋棋子外观修复设计（2026-04-25）

## Summary
- 目标：修复 `#/practice` / `#/game` / `#/analysis` 中象棋棋子“观感不对”的问题，提升接近实物棋子的质感与可读性。
- 范围：仅前端样式层（`src/main/resources/online/app.css`），不改后端 API 与棋局逻辑。

## Problem
- 当前棋子圆盘偏小（相对格点占比低），字面比例与盘面不协调。
- 棋子边框与阴影层次较弱，立体感不足。
- 字体大小与盘径比例偏紧，部分字在视觉上“挤、糊、薄”。

## Design Decisions
1. 棋子尺寸提升  
- 将棋子直径从当前约 `70%` 提升至更接近实物观感的比例（约 `82%`）。

2. 盘面材质强化  
- 采用更自然的木色渐变与双层内阴影，增强“圆盘 + 内圈”层次。
- 边框从单薄线改为更稳的深木色描边。

3. 字面可读性优化  
- 轻微下调字体上限并优化字重、字色与细微文字阴影，避免“字贴边/发黑成团”。
- 保持红黑双方配色对比，但避免过饱和。

4. 选中态与现有高亮兼容  
- 保留当前 `is-selected` 与最近一步标记机制，只调整棋子本体视觉，不影响交互逻辑。

## Non-goals
- 不改棋盘几何、河界文案、朝向映射。
- 不改落子状态机、轮询策略、接口结构。

## Validation
- 视觉回归（桌面 + 移动）：棋子大小、边框、字面观感明显改善。
- 交互回归：选中态、最后一步标记仍正常显示。
