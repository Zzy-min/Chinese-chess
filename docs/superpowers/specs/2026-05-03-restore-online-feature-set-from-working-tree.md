# 恢复线上功能集（从已验证工作树迁移）设计

日期：2026-05-03

## 背景
当前线上域名已指向最新部署提交，但用户反馈“功能被删”，页面仅剩壳层入口。  
经核对，用户长期维护的功能版本位于 `D:\claude项目\XiangqiGame` 的未提交改动集合，尚未进入 `main`。

## 目标
1. 将该工作树中的在线站点与后端能力改动迁入 `main`。  
2. 恢复用户预期功能（learn/watch/community 数据接口、practice 交互、对应前端资源与测试）。  
3. 推送后重新部署生产并验证公网可用。

## 非目标
1. 不迁移 `artifacts/` 截图与无关临时文件。  
2. 不做额外产品改版，只恢复已有功能集。

## 实施策略
1. 在隔离临时克隆中操作，避免污染现有工作副本。  
2. 仅迁移明确相关文件：`src/main/**`、`src/test/**` 的变更文件与必需新增文件。  
3. 先本地编译验证，再推送 `main`，最后执行生产部署验证。

## 验收标准
1. 线上返回的 `online` 资源与迁移后版本一致。  
2. 关键接口存在且返回正常（至少 `/online/api/site/bootstrap`、静态资源可加载）。  
3. 用户侧 UI 不再是“功能被删”的壳层状态。
