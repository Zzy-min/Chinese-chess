# 移动端手机适配、雅致底栏与学习页重构规范

## 1. 目标与背景
针对真机体验中发现的三项关键问题：
1. **界面内容全面适配手机**：防止水平溢出、右侧文字被截断、确保安全区与底栏间距（`safe-area-inset` 与 `padding-bottom` 预留）。
2. **底部导航栏质感重构**：剔除粗糙的线框图标与平淡的排列，引入古典雅致的水墨/朱红微印图标、微胶囊活跃指示态与毛玻璃宣纸底栏。
3. **学习页 UI 深度重构**：
   - 修复右侧操作区（如“登录后记录”、“标记完成”）在手机端溢出卡片边界被截断的 Bug。
   - 分类胶囊标签改为单行顺滑横向滑动（`overflow-x: auto`），杜绝折行堆叠。
   - 教程与残局卡片采用层次分明的上/中/下移动端自适应布局。

---

## 2. 界面设计规范

### 2.1 全局手机适配
- 所有页面根容器 `.mobileHome`, `.mobileLobby`, `.mobileContentPage`, `.mobileContentBody` 设置 `max-width: 100vw`, `box-sizing: border-box`, `overflow-x: hidden`。
- 底部统一保留 `padding-bottom: calc(68px + env(safe-area-inset-bottom))`，确保滚动到底部时内容完全可见，不被底栏遮挡。

### 2.2 雅致底部导航栏 (Refined Bottom Nav)
- **视觉风格**：宣纸底色毛玻璃背景 `rgba(254, 252, 248, 0.95); backdrop-filter: blur(16px); border-top: 1px solid rgba(60, 48, 36, 0.08);`。
- **图标重绘**：
  - 首页：古典楼阁/印章风格精修图。
  - 对局：双弈对局棋盘交叉点与落子微标。
  - 学习：古卷棋谱轴卷与书简微标。
  - 观战：沉浸观弈灵动之眼微标。
  - 我的：古雅弈者印章微标。
- **状态呈现**：
  - 未选中：墨灰 `var(--cl-muted, #7c7267)`，小字 11px。
  - 选中项：朱红 `var(--cl-cinnabar, #8c2e21)`，字重 750，上方图标微缩放，附带柔和的微型朱红圆点与微胶囊高亮。

### 2.3 学习页 UI 重构
- **分类横滑栏 (`learnTabs`)**：
  - `display: flex; flex-wrap: nowrap; overflow-x: auto; scrollbar-width: none;`
  - 胶囊按钮保持 `flex-shrink: 0`，选中朱红白字，未选白底墨边。
- **学习卡片 (`learnCard`) 布局重排**：
  - **头部区**：左侧古典方圆印章（`【开】`/`【中】`/`【残】`/`【五】`），右侧标题 + “有参考着法”徽标 + 难度标签。
  - **简介区**：1~2行简介，字体 13px，自然换行。
  - **操作区**：位于卡片底部横排，包含 `【参考着法】` / `【开始研究】` / `【标记完成 / 登录后记录】`，弹性自适应宽度，严禁固定死宽或绝对靠右导致溢出。
