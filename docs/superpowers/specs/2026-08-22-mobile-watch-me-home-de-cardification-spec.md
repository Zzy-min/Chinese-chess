# 移动端首页长度适配与观战/我的去卡片化设计规范

## 1. 目标与背景
针对用户提出的两项新要求：
1. **首页不要留白，长度也要适配**：
   - 彻底解决大屏/长屏手机底部出现的断层与大片空白。
   - 首页纵向节奏自适应拉伸，动态呈现 5~6 局最近战绩、今日对局宏观概况、经典残局与棋道名句，使一屏内容丰满且层次井然。
2. **观战页与我的界面去卡片化重构**：
   - **彻底根除卡片嵌套（Card-in-a-card / Card wall）**：移除观战页三层嵌套的 `.panel` 盒模型与我的页面两块孤立的浮动卡片盒。
   - **观战页**：顶置紧凑筛选条（棋种/状态/刷新），下方采用宣纸水墨单行战况列表（正在对弈 + 经典归档），配专属徽印与观战/复盘微按钮。
   - **我的界面**：打造整体感极强的古典弈者档案，包含“雅致头像区 + 4列微线战绩条 + 连续水墨功能菜单（对局记录、学习档案、成就、通知、偏好设置、帮助）”，拒绝割裂的卡片堆叠。

---

## 2. 详细重构方案

### 2.1 首页高度与内容适配 (`renderMobileHomePage`)
- **弹性高度与节奏**：容器采用 `min-height: calc(100vh - 64px); display: flex; flex-direction: column; gap: 12px;`。
- **战绩扩容**：最多展示 5 盘最近对战，展示胜负小印、对弈双方与手数。
- **古典棋理与今日弈况**：底部融入古典棋谚小条（如 `“弈棋如布阵，落子定乾坤”`），首尾呼应，杜绝空虚感。

### 2.2 观战页去卡片化 (`renderWatchPage` & `renderWatchRooms`/`renderWatchGames`)
- **顶栏筛选**：
  `<div class="clWatchFilterBar">` 提供棋种、状态下拉选择与刷新按钮，单行排布。
- **正在对弈列表 (`.clWatchSection`)**：
  - 标题：`【弈】 正在对弈`，显示实时对局房间。
  - 单行战况：`[象/五] 玩家A 对 玩家B · 进行中 · 第 N 手` + 朱红 `[👁️ 观战]` 按钮。
- **经典归档列表**：
  - 标题：`【谱】 经典对局归档`。
  - 单行回放：`[谱] 玩家A 对 玩家B · 38回合 · 胜负` + 墨色 `[复盘分析]` 按钮。

### 2.3 我的页面去卡片化 (`renderProfile`)
- **移动端专属 Profile 视图**：
  - **头部**：大号朱红印章头像 `【zzy】`，弈者称号 `棋友 · 778382f9`，右侧 `[⚡ 快速开局]` 按钮。
  - **战绩数据条**：4 列微墨线网格（总对局、胜率、胜负、成就数）。
  - **水墨条目列表 (`.clProfileMenu`)**：单行带有微图标与 `›` 箭头的连续列表，无外框卡片阴影：
    - `📜 对局记录`
    - `📚 学习档案`
    - `🏆 我的成就`
    - `🔔 消息通知`
    - `⚙️ 偏好设置`
    - `❓ 规则与帮助`
  - **子页面导航**：进入对应子菜单时，顶部带有极简返回条 `‹ 返回个人中心`，下方直接呈现对应数据，保持全站一致的古典极简水墨风格。
