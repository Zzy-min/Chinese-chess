# 移动端古典简约与高效化重构 - 验证与验收报告

## 1. 概述与设计目标
针对用户提出的需求：**“重新整体设计，追求古典简约，效率至上，不要用过大的卡片式布局”**，本次重构对移动端全站进行系统性重构与精简：
1. **去大卡片化（De-cardification）**：彻底移除原来高达 300px 的臃肿 Hero 卡片与层层包裹的卡片墙，首屏直接呈现核心行动项。
2. **古典雅致（Classical Minimalist Aesthetics）**：采用宣纸底色（`#fcfaf6`）、水墨细线描边（`rgba(60,48,36,0.12)`）、朱红与松青古典印章（`【棋】`、`【配】`、`【机】`、`【房】`、`【残】`）与宋体/楷体标题。
3. **效率至上（Efficiency First）**：
   - **90px 极速对弈 Ribbon**：即点即配，一键进入 5 分钟快棋。
   - **2×2 精简模式矩阵**：真人对决、AI 磨砺、好友约局、残局闯关一屏全览。
   - **高密度单行战绩流**：一屏展示 4 盘最近战绩，带微型朱红/墨色胜负标签与棋谱快速回看。
   - **快速呼出开局抽屉（Quick Start Bottom Sheet）**：底部半屏抽屉快速切换象棋/五子棋与匹配/人机/建房。
   - **去卡片化的学习/观战/棋友页**：直接置顶筛选胶囊与紧凑列表。
