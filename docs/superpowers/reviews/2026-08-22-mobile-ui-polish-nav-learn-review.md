## 1. 任务背景与解决问题
针对用户提出的三点要求：
1. **界面内容适配手机**：排查并彻底解决手机端的水平溢出、右侧文字或按钮被截断、以及页面底部被导航栏遮挡问题。
2. **底部导航栏质感重绘**：替换原有粗糙的线框图标与平淡排版，重绘古典微图标（楼阁首页、弈棋对局、卷轴学习、灵动观战、雅士我的），加入朱红微胶囊高亮、宣纸毛玻璃底栏与平滑切换动效。
3. **学习页 UI 呈现全面重构**：
   - 彻底修复学习卡片右侧“登录后记录”与“标记完成”按钮在移动端溢出截断的 Bug。
   - 顶部分类筛选胶囊改为单行横向顺滑滚动（`overflow-x: auto`），解决多行折叠堆叠问题。
   - 学习卡片重构为上（印章+标题+难度）/中（简介）/下（自适应操作按钮）三段式结构，支持展开详细着法与练习清单。
