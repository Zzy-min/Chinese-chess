# 移动端适配、底栏质感重构与学习页修复实施计划

根据用户提出的三点要求：
1. **界面内容适配手机**：防止溢出、确保边距与安全区。
2. **底部导航栏太丑**：重绘古典雅致微图标、优化排版与选中态。
3. **学习页 UI 呈现有问题**：解决右侧按钮溢出被截断问题，横滑分类胶囊，重构卡片信息层次。

## 拟变更内容

### 1. `src/main/resources/online/app.js`
- **重构 `renderLearnItemCard`**：
  - 改造内部 DOM 结构，移除右侧固定靠边弹性盒造成的溢出。
  - 使用语义化 class，支持自适应换行与操作按钮区。
- **重写 `mobileIcon` 与 `renderMobileBottomNav`**：
  - 精修 5 个底部导航专属图标路径（更细腻的中国风线条与比例）。
  - 规范导航项目结构与 class 绑定。

### 2. `src/main/resources/online/mobile.css`
- **全局与页面适配**：
  - 为所有移动端页面与容器设置安全内边距与防水平溢出规则。
  - 统一底部 `padding-bottom: calc(72px + env(safe-area-inset-bottom))`。
- **底部导航栏样式升级**：
  - 设置高质感宣纸毛玻璃底色、精致水墨微印、朱红微胶囊高亮与灵动指示点。
- **学习页专项样式**：
  - `.learnTabs` 横向平滑滚动与隐藏滚动条。
  - `.learnCard` 三段式紧凑自适应卡片与古典小印。
