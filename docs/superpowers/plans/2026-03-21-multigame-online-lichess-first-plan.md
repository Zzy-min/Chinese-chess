# 三棋在线棋站首版实施计划

## 阶段 1：文档与测试基线

- 写入设计文档和实施计划。
- 新增后端核心测试：
  - 注册/登录/重复用户名。
  - 房间创建、加入、准备、开始。
  - 在线对局状态推进与结果落盘。

## 阶段 2：在线后端基础

- 引入嵌入式在线服务器栈，支持 HTTP 与 WebSocket。
- 引入 Postgres 连接层和启动时 schema 初始化。
- 实现用户、会话、房间、对局、走子记录仓储。
- 实现密码哈希和 Cookie 会话认证。

## 阶段 3：在线对局运行时

- 建立 `OnlineMatch` 抽象。
- 实现象棋在线对局引擎。
- 实现五子棋在线对局引擎。
- 为围棋保留能力状态和入口占位。
- 实现房间运行时和实时广播。

## 阶段 4：站点与前端

- 新增公共在线站点首页、导航、认证页、大厅、房间页、对局页、分析页。
- 保留观战/社区/个人页壳层。
- 将房间创建和加入前移到大厅。
- 对局页只承载局内操作与走子状态。

## 阶段 5：验证

- 运行单元测试和构建验证。
- 核查认证、房间、在线对局、分析链路是否能通过接口完成。
- 明确记录实际完成项、未完成项和残余风险。
