# Node/TS 新主站能力矩阵

更新时间：2026-03-25

## 已开放

- 首页：四棋入口、清新版视觉、棋盘预览、能力状态面板
- 账号体系：站内注册、登录、登出、基于 cookie 的会话识别
- Play：大厅浏览、建房、通过房间码查房、进入房间
- 在线房间：四棋都支持加入、准备、开始、局内操作
- 在线局内：
  - 中国象棋：服务端裁判落子、盘面更新、走子历史
  - 五子棋：服务端裁判落子、盘面更新、胜负判定
  - 国际象棋：服务端裁判、合法走子、棋盘与步列表同步
  - 围棋：服务端裁判、19 路盘面、停一手、双停结算
- 房间同步：房间详情页已切到 WebSocket 房间订阅
- Practice：四棋都支持创建真实练习局，结束后可归档
- 持久化：用户、会话、活动房间、活动练习、归档、排行榜统计已落到本地文件数据库
- 历史页：登录后可查看在线对局与练习归档，并按棋种/来源过滤
- 回顾页：支持归档回放、步进、结果摘要、关键标签、参与者信息
- 个人页：展示用户资料、四棋基础统计和最近归档
- 排行榜：四棋在线对局基础积分榜
- Learn：四棋学习入口壳层，页面内显示当前能力矩阵
- 能力接口：`GET /api/site/capabilities`

## 部分开放

- 持久化：本地验证采用 SQLite 文件数据库，数据层已按可迁移接口组织，但当前不是实际 PostgreSQL 运行环境
- 活动态恢复：服务重启后历史与归档不会丢，但未承诺所有未完成活动局都能无缝继续对弈
- 回顾分析：当前是高质量回放与轻量标签，不是深度引擎分析
- 房间同步：大厅列表仍是 HTTP 拉取，房间详情页才是 WebSocket

## 未开放

- 第三方登录
- 深度逐步分析 / 强算点评
- 自动匹配、观战、评论、社区系统
- 复杂权限模型

## 验收口径

“功能完备”指当前新主站声明支持的能力链路可注册、可登录、可对局/练习、可归档、可历史查询、可回顾，不代表后续高级产品能力已经全部完成。
