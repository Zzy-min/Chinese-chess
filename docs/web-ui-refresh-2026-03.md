# 浏览器版 UI 更新日志（2026-03）

本轮更新聚焦网页端视觉层级、信息组织方式和前端可维护性，目标是在保留古风氛围的前提下，让棋盘更突出、操作更顺手、后续迭代更轻松。

## 这次改了什么

- 页面主结构重做为“棋盘主舞台 + 局阁抽屉侧栏”
- 顶部集中展示品牌、状态、步时与总时，减少信息分散
- 主操作固定在棋盘区域附近，开局、悔棋、认输、和棋、音效切换更直接
- 设置、残局、复盘拆成分区卡片，避免所有控件堆在同一列
- 五子棋与中国象棋继续共用同一套页面框架，但根据棋种自动显隐相关面板
- 手机端改为抽屉式侧栏，减少窄屏遮挡和误触

## 代码结构调整

- 首页不再由 `WebXiangqiServer.java` 直接拼接整段超长 HTML 字符串
- 新增独立页面资源目录：`src/main/resources/web`
- 页面拆分为：
  - `index.html`：页面骨架
  - `app.css`：视觉风格与响应式布局
  - `app.js`：页面逻辑与现有棋盘渲染逻辑整合
- 服务端新增 `/assets/ui` 静态资源访问路径，用于提供网页端样式与脚本

## 设计方向

- 主题延续古风器物感，强调暖木、鎏金、宣纸、漆面质感
- 棋盘依旧是页面核心，不让装饰元素压过对局本身
- 信息密度从“堆叠式”调整为“分层式”，让用户更容易找到当前需要的控制项

## 对玩家有什么变化

- 首屏更容易看清当前局面、当前状态和主要操作
- 进入残局或复盘时，切换逻辑更清楚
- 在手机浏览器中更容易点按和切换功能区
- 后续如果继续做界面优化或补充新模块，修改成本会明显下降
