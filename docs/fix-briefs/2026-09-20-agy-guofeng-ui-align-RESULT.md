## 三、与真源图（2026-09-20-guofeng-ui-reference.png）诚实差距说明

对照 8 屏真源图详细核对，当前落盘代码与真源图存在的具体差距如下：

1. **水墨手绘素材层差距（非布局结构问题）**：
   - **首页 Hero 装饰**：真源图屏 1 的大标题左右两侧有精美的半透明水墨扇面、入画棋盘与远山云雾；当前工作区使用 CSS 渐变与占位背景类模拟，缺乏定制高清手绘水墨原画切图。
   - **大厅模式卡插画**：真源图屏 2 的「在线象棋」卡内有 3D 浮雕感的红黑棋子立体斜切图，「五子棋」卡内有水墨棋罐与棋子散落插画；当前界面为 CSS 纯色块与图标示意。
   - **对局页背景水印**：真源图屏 3/4 在左下角有淡淡的行舟/垂钓水墨水印，当前界面为素宣纸白卡。

2. **未实现页面（按 Brief 要求「无则不假造」，不造假入口）**：
   - **好友中心即时通讯（真源屏 5）**：真源包含好友列表、在线状态绿点、双向聊天气泡及聊天输入框。由于仓库现有架构并无即时聊天 IM 后端，本轮未盲目实现空壳聊天界面。
   - **赛事活动公开赛（真源屏 6）**：真源包含比赛时间轴、参赛人数卡片及「立即报名」CTA。由于缺乏赛事报名与编排系统，本轮未捏造假赛事流。
   - **个人中心成就墙（真源屏 8）**：真源个人中心有「我的勋章（12枚）」、「我的成就（24项）」卡片与徽章图标展示；现站 `#/me` 仅有基础用户对局数、胜率及胜负场次统计，未凭空伪造勋章数据墙。

3. **字体渲染环境差异**：
   - 真源图中的「落子之间，自有风雅」及书法印章文字使用了高精书法题字；在无本地商用字体包嵌入的纯浏览器环境下，回退至 `Noto Serif SC`、`Songti SC` 或宋体渲染，字形风格偏现代印刷宋体，传统毛笔书法味稍弱。

4. **棋子光影与材质**：
   - 真源图中象棋子带有木质切角与边缘微高光，五子棋石子有玉脂反光；现站棋盘基于 Canvas/SVG 扁平渲染，棋子更偏矢量国风，物理质感比真源图清淡。
