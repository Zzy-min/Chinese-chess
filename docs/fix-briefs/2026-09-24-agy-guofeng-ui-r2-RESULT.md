## 三、与真源图及现站截图诚实差距说明

对照 8 屏真源图（`2026-09-20-guofeng-ui-reference.png` 屏 3、屏 4）与 2026-09-21 现站真盘截图（`03-xiangqi-game.png`、`04-gomoku-game.png`），本次改动后存在的客观技术环境与素材差距如下：

1. **手绘矢量 SVG vs 手绘光栅插画**：
   - 真源图左下角的行舟与棋篓具备丰富的手绘水墨浓淡干湿细节；本次实现采用高兼容、零外部请求的纯矢量 SVG 与 CSS 渐变，线条比例与意境形态严格对齐真源，但在毛笔枯笔飞白等笔触肌理上稍逊于顶级手绘美术原画。
2. **棋子 3D 浮雕光影度**：
   - 真源图中棋子带有斜切倒角圆饼质感与顶部漆面反光；现站基于 Canvas/SVG 扁平文字与轻径向渐变，虽然木质感已明显加深，但棋子边缘的微物理倒角反光仍偏向矢量国风风格。
3. **楚河汉界书法题字字体依赖**：
   - 楚河汉界已设置优先调用 `KaiTi` / `STKaiti` / `Songti SC` 等传统书法字体；在缺乏中文字体环境的特殊 Linux 或纯精简容器客户端中，文字将回退至系统 serif，字形略显工整印刷感。
