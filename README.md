# 轻·象棋（XiangqiGame）

一个基于 Java 的中国象棋项目，提供 **桌面版（Swing）** 与 **浏览器版（本地 Web）** 两套对局模式。  
A Java-based Xiangqi project with both **desktop (Swing)** and **browser (local web)** play modes.
